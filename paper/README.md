# Paper

Light theme: warm off-white paper with ink-like colors.

![Paper preview](preview.svg)

## Install

1. Download [`Paper.terminal`](Paper.terminal).
2. Double-click it (or Terminal → Settings → Profiles → ⋯ → Import).
3. Select **Paper** and click **Default**.
