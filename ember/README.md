# Ember

Warm charcoal with copper, amber, and clay accents.

![Ember preview](preview.svg)

## Install

1. Download [`Ember.terminal`](Ember.terminal).
2. Double-click it (or Terminal → Settings → Profiles → ⋯ → Import).
3. Select **Ember** and click **Default**.
