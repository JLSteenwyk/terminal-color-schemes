# Fjord

Cool blue-slate with soft, low-glare accents.

![Fjord preview](preview.svg)

## Install

1. Download [`Fjord.terminal`](Fjord.terminal).
2. Double-click it (or Terminal → Settings → Profiles → ⋯ → Import).
3. Select **Fjord** and click **Default**.
