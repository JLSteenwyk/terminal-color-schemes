# Dusk

Twilight indigo with sunset rose, peach, and lavender.

![Dusk preview](preview.svg)

## Install

1. Download [`Dusk.terminal`](Dusk.terminal).
2. Double-click it (or Terminal → Settings → Profiles → ⋯ → Import).
3. Select **Dusk** and click **Default**.
