# Arcade

High-energy synthwave neon on near-black.

![Arcade preview](preview.svg)

## Install

1. Download [`Arcade.terminal`](Arcade.terminal).
2. Double-click it (or Terminal → Settings → Profiles → ⋯ → Import).
3. Select **Arcade** and click **Default**.
