# Tahoe

Deep lake teal with granite grays and clear-water cyans.

![Tahoe preview](preview.svg)

## Install

1. Download [`Tahoe.terminal`](Tahoe.terminal).
2. Double-click it (or Terminal → Settings → Profiles → ⋯ → Import).
3. Select **Tahoe** and click **Default**.
